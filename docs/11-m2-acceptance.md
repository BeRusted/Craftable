# M2 验收报告：单步合成与补偿式事务

- 实现日期：2026-09-03
- 环境：Minecraft 1.21.1 / NeoForge 21.1.235 / Java 21
- 当前结论：**自动验收与全部人工复测通过，M2 已完成**

## 1. 已落地能力

- 一次请求只执行一个普通原版 `SHAPED_RECIPE` 或 `SHAPELESS_RECIPE`，没有引入递归、批量、炉类或第三方动作；
- 每次创建都绕过预览缓存，取得新环境快照并重新规划；
- 2×2 使用玩家固有能力，3×3 必须在同一快照中发现附近工作台；
- 材料分配使用最多九层的“候选最少优先”回溯，避免宽标签先错误吃掉精确材料；
- 使用真实 `CraftingInput` 执行 `matches`、`assemble` 与玩家上下文中的 `getRemainingItems`；
- 输出与全部剩余物联合模拟进入玩家主背包，任何一个栈放不下都不提取材料；
- 提交前以物品、数量和数据组件复验来源槽；提取中途失败会恢复玩家 36 个主背包槽及全部受影响原版来源槽；
- 成功后触发 `ItemStack.onCraftedBy`、NeoForge `PlayerEvent.ItemCraftedEvent`、原版配方判据与配方解锁；
- 尊重 `doLimitedCrafting`，新增本地化的 `RECIPE_LOCKED` 失败结果，网络协议版本升级为 3。

## 2. 防架构偏移审计

- `DirectCraftingService` 仍是唯一公开门面；新增实现仅为三个包私有类：规划器、事务执行器和主背包插入器；
- 网络层没有获得槽位、输入、输出或事务内部控制权；
- 没有创建 `planner`、`compat`、动作 SPI、事务总线、历史存储或第二套环境扫描器；
- 没有触碰 M3 的配方书集合、三态筛选和实体 3×3 菜单；
- 没有实现 M4 递归/部分完成、M5 炉类或 M7 撤销；
- GameTest 复用 Mojang 空结构，仅在开发运行配置中额外允许 `minecraft` 测试模板命名空间，不增加生产玩法资源。

## 4. 已知且有意保留的限制

- 仅支持 `minecraft` 命名空间的普通有序/无序工作台配方；特殊、动态及第三方配方返回“不支持”；
- 一次只制作一份目标配方，不递归制作中间产物，不做“尽可能完成”；
- 所有产物和剩余物只进入玩家 36 格主背包；不自动回填来源箱子，也不向世界掉落；
- NeoForge 制作事件在物品提交后作为通知触发。监听器抛错不会回滚物品；监听器对事件输出副本的修改不会重写已插入结果；
- M0.2 已确认的配方书集合、`showing craftable` 与背包实体 3×3 虚影问题仍属于 M3。

## 6. 两轮人工复测结果

实际测试使用 `runClient` 开启局域网，另一台设备以相同版本和 `build/libs` 中的模组 JAR 加入；根目录 `client.log` 记录 WARN 及以上日志。

- A：不完全通过。木棍按钮在木板配方与竹子配方间轮播时，绿框同步闪烁；显示竹子配方的阶段按 `C` 会错误提示材料不足；
- B：通过。因原版在无工作台时会隐藏钻石镐条目，采用先打开背包、由另一玩家拆除和重新放置工作台的方式验证；
- C、D、E：通过；
- 日志未发现 Craftable `ERROR`；现有 WARN 为开发环境中的 NeoForge/原版警告，没有指向本次事务失败。

根因是旧客户端把 `RecipeButton#getRecipe()` 返回的动画当前项同时当成显示状态和执行目标。现已改为按整个按钮候选集合聚合状态，并优先选择服务端已确认可制作的候选。

轮播目标修复后的定向复测使用同版本新 JAR，以下项目全部通过：

- [x] 附近箱子只放两块木板，悬停木棍按钮至少 10 秒并跨越多次图标轮播：绿框持续稳定；
- [x] 分别在木板配方和竹制配方的轮播阶段按 `C`：均选择可行的木板配方，不出现周期性“材料不足”；
- [x] 反向仅提供竹子时重复测试：按钮仍稳定可制作并选择竹制配方；
- [x] 局域网第二台设备换用本次新 JAR 后重复上述测试；
- [x] `client-M2-retest.log` 中没有 Craftable `ERROR`，也没有任何 `ERROR/FATAL`。

B 中“没有工作台时原版配方书隐藏 3×3 配方”属于已登记的 M3 全配方目录与筛选问题，不回填进 M2。

本轮另观察到两个不影响 M2 事务正确性的 M3 问题：

1. 可制作物品在鼠标首次悬停前没有绿框，说明 M2 原型仍以悬停作为状态请求入口；
2. 成功制作后客户端清空状态缓存，在新预览返回前短暂回退为不可合成，形成一次可见闪烁。

两项均已进入 M3 的主动可见页预取和状态过渡验收条件。至此 M2 正式关闭。
