# ADR-0002：环境快照是短期服务端契约

- 状态：已接受
- 日期：2026-09-02
- 适用里程碑：M1 及以后

## 背景

M0.2 扫描器直接返回包含活 `Container` 的列表，并以世界时间充当世代。预览请求每次重新扫描，执行器也可直接调用扫描器。继续扩展会导致缓存、配置、客户端状态与事务复验各自形成一套环境语义。

## 决策

1. `EnvironmentSnapshotService` 是运行时取得工作环境的唯一入口；
2. 预览读取按玩家、维度、方块原点和扫描设置约束的短缓存；
3. 创建与其他资源变更操作必须强制生成新快照；
4. 环境世代是按玩家单调递增的服务端序号，不使用世界时间；
5. 快照包含活容器句柄，因此只在服务器主线程短期存在，不序列化、不持久化、不发送给客户端；
6. 网络只发送目标和结果摘要，调试命令只输出结构摘要。

## 结果

M2/M3 可以共享同一环境世代和失效语义，状态缓存不会变成第二套资源真值。代价是扫描器不再是任意位置可直接调用的工具类，测试必须分别覆盖纯缓存策略和世界扫描集成。

## 被否决的方案

- 每 tick 主动扫描：空闲成本与范围体积不可接受；
- 把完整库存同步到客户端：泄露信息并扩大作弊面；
- 持久化快照：活容器、区块和权限状态不能安全跨会话复用；
- 让各功能自行扫描：会产生不一致的范围、锁与双箱语义。
