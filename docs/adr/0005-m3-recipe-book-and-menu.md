# ADR-0005：M3 配方状态投影与临时背包工作台菜单

- 日期：2026-09-06
- 状态：已接受，已实现；2026-09-08 玩家验收完成，观察项见 M3 验收报告第 9 节。

## 决策与取证

原版 `ClientRecipeBook.setupCollections` 已经用同步配方建立目录；解锁、尺寸和可制作过滤发生在 `RecipeCollection`。因此复用目录对象，在 Craftable 背包界面活动期间投影其可见/可制作集合，离开时恢复原版计算。不会调用授予配方 API。

`RecipeBookComponent.updateCollections` 在可制作过滤前选择分类和搜索结果；`RecipeBookPage` 持有 20 个按钮。协调器优先查询可见页，并在仅可制作筛选中轮询当前分类/搜索命中的隐藏候选，避免未查询的配方永久无法进入列表。每批最多 32 个 ID，每玩家每 4 tick 一批，同批共享一个环境快照；响应接受后在下一次界面 tick 更新集合，避免渲染中更换按钮导致索引越界。

缓存生命周期与业务状态分离。等待刷新时保留上次状态并标注待确认。创建响应使缓存待确认，同时用请求序号屏障拒绝创建前的响应；因为主背包输出容量影响全部配方，M3 保守使已有条目全部过期，但仅刷新当前视图，暂不建立材料依赖索引。

`CraftingMenu` 已完整处理 3×3、ResultSlot、配方放置、Shift 点击及关闭返还；`CraftingScreen` 已完整集成配方书。因此注册其小型子类，保留原版 0–45 槽对象与 ID（包括 ResultSlot），末尾追加护甲与副手 46–50 槽。复用 CraftingScreen 的交互，以及 InventoryScreen 的公开人物渲染函数和原版 inventory.png 背景。护甲、副手、人物与主背包保持原版坐标，九宫格在右上，输出置于其下，配方书按钮在副手上方。独立 common accessor 只允许设置既有 Slot 的 x/y，客户端与服务端使用同样布局；它不接触库存、匹配和结果回调。移除原装备侧栏与宽度补偿。服务端确认工作台后用正常 openMenu 打开；Player.inventory 和 inventoryMenu 均不替换。无工作台仍使用原版 2×2；工作台失效后关闭临时菜单并按原版返还/掉落规则处理网格。能力仅限生存/冒险。创造模式保持原版目录，不添加任何按钮、不请求菜单/预览、不响应 C；旁观同样无能力。临时菜单进入禁止模式时在下一游戏 tick 安全关闭和返还，然后回到创造目录或旁观 HUD。返回生存/冒险不自动升级，等待下一次玩家打开背包。客户端输入/投影与服务端预览/创建/菜单授权共用纯 GameType 判据。

3×3 工作台失效使用原快照内工作台位置、维度与当前范围逐次复验；输入操作必须先检查 stillValid。关闭/死亡/断线沿用原版菜单生命周期。普通配方左键只放置背包材料或虚影，附近材料使用 C；2×2 上的 3×3 目标只展示原因，不把虚影放进错误槽位。

实体工作台 CraftingScreen 复用同一投影、预取、过滤、Tooltip 和 C；有效原版菜单自身也是 3×3 工作站。Tooltip 用独立简短原因翻译键合并状态，不复用“制作失败”通知全文。角标在物品层之上绘制，不改变 Toast。

## 边界

2026-09-07 视觉修订：合成网格维度不决定结果槽高亮尺寸。临时背包使用 16×16 结果内容区，既有 RecipeBookComponent Mixin 仅为 AmbientInventoryMenu 将原版 renderGhostRecipe 的大结果标记设为 false；实体工作台仍使用原版 24×24 外扩高亮。不复制 GhostRecipe/CraftingScreen 渲染，不改槽位、事务或协议。

M2 执行器仅扩展合法上下文为原版 CraftingMenu 家族；环境和事务仍独立复验。批次预览不暴露计划/库存，不允许客户端指定数量或成本。M3 不提供递归、撤销、炉类或最大数量批量执行。

## 索引与刷新回归

模式切换撤销投影时，旧按钮还可能存活一个渲染帧。索引/空列表安全检查在支持的配方书屏幕内保持有效，不随能力开关提前退出；颜色、预取、C 则立即停止。关闭到 null 不触发 NeoForge Opening，因此使用 Closing 恢复原版集合，并在服务端完成关闭与返还后再于客户端 tick 进入创造目录，避免双重关闭或丢失切换意图。

用户提供的 `13.53.34` 与 `13.55.06` 崩溃报告显示：原版按钮重绑定为 1 个候选后，旧动画索引仍为 9 或 3。背景绘制回调早于原版重算动画索引，旧状态解析器此时调用 `getRecipe()` 导致越界。固定措施是：状态/目标选择不依赖动画帧；重绑定与所有原版读取入口校正索引，空列表直接停止该次操作；相同服务端结果只更新时间戳，不触发集合重建。开发专用客户端脚本连续 200 tick 切换分类/搜索/筛选，并注入上述旧索引作为回归。
