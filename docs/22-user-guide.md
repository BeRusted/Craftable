# 玩家指南

中文名：配方书；英文名：Craftable；模组 ID：`craftable`。中文设置标题为“配方书设置”，英文设置标题为“Recipe Book Settings”；设置页使用配方书术语，NeoForge 模组元数据中的英文名称及原有文件/命令不变。

## 1. 当前可以做什么

当前代码为 M4 关闭后的 Pre-M5：Minecraft 1.21.1、NeoForge 21.1.235、Java 21，新增直接部分准备规则使用网络协议 11。联机两端须使用同一份对应加载器的新 JAR，不混用协议 9 的 M4 历史或协议 10 的此前 Pre-M5 构建。各批次身份及历史失败见 [验收跟踪](21-pre-m5-transition.md#7-验收跟踪)。7.8 修复续期按钮刷新，7.9 整理服务端审阅开销；该批次 114 项单元、149 项服务端及两次独立 JVM 无诊断全量客户端通过，确认问题暂视解决，真正预算耗尽仍安全拒绝。7.10 单独登记新增规则构建；10 月 13 日用户完成第 8 节基础设置人工测试，见 7.11。8.1 新名单和此后的中文名仍待复测，旧构建结果不替代新改动验收。

Craftable 使用当前可用材料和普通原版合成配方，自动准备必要的中间物品并合成目标。生存/冒险模式可用；创造/旁观不提供此能力。附近有可用工作台时，背包提供真实 3×3 合成格；实体工作台的配方书也支持同样操作。

炉类处理、Z 撤销、JEI/第三方条目、地面掉落物与实体库存、便携盒/收纳袋内部材料尚未实现。原生分类/收藏/稳定排序改进安排在 M6，便携资源与末影箱物品钥匙规则安排在第二阶段 R1；详见 [路线图](01-roadmap.md) 和 [Pre-M5 计划](21-pre-m5-transition.md)。

## 2. 制作与查看

- 鼠标指向配方，按 **C**：完成一次该配方。原配方一次产出四块木板时，得到的也是四块，不拆分原版产量。
- 完整制作失败后，对同一目标按/松开两次 C：明确请求尽可能准备当前目标需要的材料。第一次失败和普通长按不会自动消耗部分材料。
- **Shift+C**：查看物品链、换配方或最终成品材质、选择次数/MAX，再按“合成”。打开详情或拖动数量本身不会消耗材料。
- 原版左键填格仍只使用随身材料；需要从附近容器取料时使用 C。
- 键位可在原版控制设置中修改；Shift+C 跟随已绑定的制作键，不是另一个独立绑定。聊天/搜索输入不会被 C 抢走。

配方按钮显示可合成、部分可合成或不能合成，并在 Tooltip 解释原因。刷新时保留上一已知页面；旧颜色不是永久执行承诺，服务器会在实际制作前重新检查资源和权限。未知/仍在计算不等于材料不足。

同一种成品的替代原料可自动选合适路线；不同材质的船等成品按当前展示/选中的材质制作，不应自动换成列表里的第一种。详情页的手选配方或成品变体改变后，整条链和用量会重新计算。

## 3. 哪些材料算当前资源

当前包括主背包、当前 2×2/3×3 合成格和光标、附近可用的原版方块容器；结果格不是原料。物品只是从主包移到光标或当前合成格，不应让配方书突然认为材料消失。装备/副手不作为普通可消耗材料。

容器须已加载、在检测范围内、可打开且有权限；阻挡、锁住或未生成战利品的容器不能被绕过。多个视图不会让同一份材料重复计数。非默认组件的物品默认受保护，不为递归制作自动消费自定义名字、内容等特殊物品。

目前需要附近存在已放置且可用的末影箱，才能使用自己的末影库存。用户已确认的后续规则是“持有或已授权环境中有末影箱方块物品即可作为钥匙”，但 R1 尚未实现；不会扫描远处方块，也不会访问其他人的末影库存。潜影盒已放置成可用方块容器时可用，随身潜影盒/收纳袋内部材料尚不可用。

## 4. 数量、空间与部分准备

数量是根配方执行次数，不一定等于成品件数。MAX 只在已证明时显示确切最大次数；尚未证明时显示可行下界，不能把“至少”理解成完整上限。

世界规则最多允许 64 次根配方，整条链的实际配方执行次数默认 128，可配置为 1–256，包含根批次和中间步骤。例如原木加工成木板也占步骤；材料很多不保证本次能全部做完。调高步数不会增加计算时间、内存或传输大小限制，MAX 仍可能只知道“至少”；M4 历史关闭基线的 128 步记录不因此改变。

成品必须放得进主背包。余料默认也要收纳；世界允许时，可仅把放不下的余料按原版方式丢出，存在丢失风险。个人设置可以额外禁止余料掉落，不能放宽世界规则。部分准备只做当前目标所需且允许的最少完整批次，不把全部原木无条件转成木棍；背包没有空间时仍可能拒绝。

服务端“直接部分准备规则”控制哪些实际加工步骤可省去额外确认，而不是哪些完整配方能合成：

- 自定义规则（默认）：当前低风险木材加工、木棍/竹子、精确存储转换仍按输入和产量判断；可用完整配方 ID 添加“允许直接准备”或“需要确认”覆盖，同一个 ID 两边都有时需要确认。
- 全部允许直接准备：只针对已支持并通过全部校验的配方；仍须先明确请求部分准备，单次 C 失败不消费材料。
- 全部需要确认：仍能查看并确认部分方案，并非完全禁止。要禁止部分合成，用世界或个人缺料策略“禁止”。

切换快捷模式不会删除自定义名单。名单保存具体配方，不把某物品的所有不同配方一起放行；每张表最多 128 项、ID 最多 128 字符。合法但不存在/不支持的 ID 暂不生效，不能因此用炉类或第三方机器。默认不是只认熟悉的 ID：数据包保留原版名称却改成昂贵配方时，不能自动继承低风险许可。管理员显式允许这些配方代表接受材料风险；受保护输入、来源权限、解锁、容量和计算预算仍有效。个人“先确认”与“禁止”也不能被该规则放宽。

## 5. 设置在哪里

在原版“选项 → 辅助功能设置”的可滚动列表中找到“配方书”（英文为 Craftable），打开“配方书设置”。入口是半宽按钮，会补在末行空着的右侧；末行占满时自然新开一行，不固定在某个原版选项旁。独立设置主页直接以双列显示六项个人选项，不再需要进入个人设置二级页：配方书增强、仅已解锁配方、详细失败提示、缺料合成、丢出余料和双击间隔。短标题的完整含义可查看 Tooltip，多选策略的说明逐项另起一行，中文说明避免句号独占一行。页面底部说明以上部分个人偏好受当前世界规则影响。可编辑页底部从左至右为“取消 → 默认值 → 完成”：控件先改草稿，“完成”才保存，“取消”或 Escape 不保存，“默认值”也需完成后才保存。世界规则仍在独立入口，不直接混入原版辅助功能列表。

多人或已开放 LAN 时，主页提供“查看世界规则”，显示最近读取的世界/服务器规则，包括扫描范围、末影入口、部分/余料策略、单次合成上限、整链步骤上限与直接部分准备规则。这是一份只读快照，不是始终实时的承诺；“重新读取规则”与“完成”并排放在页面底部，不在列表内放来源说明或重读条目。重读按钮的 Tooltip 和旁白提供读取状态、来源与错误，读取中禁止重复请求。重读本身不会刷新合成预览或授予制作权限，尚未收到值或超时不拿本地服务器 TOML 冒充远端规则。

单人未开放局域网且世界配置已加载时，主页的“编辑世界规则”打开基础规则、直接部分准备模式及配方名单入口，底部从左至右为“取消 → 默认值 → 完成”，不显示来源说明或重读按钮。同样先改草稿，父世界页完成才保存，取消或 Escape 不保存；普通页不显示诊断缓存。名单子页按产出物品 ID/配方 ID 排序，可搜索名字、物品 ID 或配方 ID；每个配方选择默认、允许或需确认，Tooltip 显示默认判断及投入/产量。超过单次 256 条时缩小搜索，可手动输入完整未知 ID 并保留为暂不生效。子页完成只回父草稿，父页取消仍不保存；两种界面共用同一模式与两张名单，不另设配置副本。未进入世界时，普通页的世界入口不可用；世界配置尚未加载时也不能编辑。编辑时若换世界或开放 LAN，会禁止保存，需返回后重新打开。远程玩家（包括 OP）和已开放 LAN 的页面只读，个人偏好只能收紧世界限制。NeoForge“模组 → Craftable → 配置”及“高级配置”保留专业页的原生入口与权限，共享同一设置定义与 Tooltip，其底部仍为 NeoForge 自身的取消、重置、完成；其 SERVER 配置未加载时亦不可编辑，不另提供未来世界默认规则模板编辑。未实现的炉类或 R1 不出现空按钮。

名单目录加载中或暂不可用时会明确提示，已保存的 ID 覆盖仍保留；这不是“没有配方”，也不代表该 ID 的默认许可已经确认。改变规则后，旧详情、MAX 与确认会失效，刷新后按新规则计算；旧 token 不能扣料。新增规则不要求重建静态配方目录，设置页的“重新读取”也不是合成授权。操作增补复测见 [P5a 人工清单](21-pre-m5-transition.md#81-p5a-增补复测待人工)。

打开高级配置会保留主页尚未保存的个人草稿。返回时，已经手动改过的项目保留这份草稿，未改项目更新为专业页的新值。专业 NeoForge 页面沿自己的修改/保存方式生效；在普通页取消不会撤销专业页已经保存的更改。

普通页面已隐藏 `previewCacheTicks`：旧键只影响环境诊断命令的短缓存，值 0 禁用，不控制配方书/详情刷新，也不能让制作使用旧材料。高级页仍保留该诊断项，见 [配置说明](04-compatibility-and-config.md#7-配置)。

## 6. 反馈问题时提供什么

请记录加载器/游戏版本、所有机器是否使用同一 JAR、单人或远程/局域网、目标配方/材质/次数、材料的位置及数量、主背包空位、操作顺序和可复现截图。若提供日志，注明实际文件名与对应时间；不上传其他玩家私有库存或敏感路径。

开发者的自动测试命令与人工边界集中在 [测试索引](../tests/README.md)。M4 人工结果已关闭，不要求玩家为了新文档重做旧清单；Pre-M5 新设置状态单独记录在 [验收跟踪](21-pre-m5-transition.md#7-验收跟踪)，本轮待测操作见 [简短人工清单](21-pre-m5-transition.md#8-本轮人工验收清单)。
